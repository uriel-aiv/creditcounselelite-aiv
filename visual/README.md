# Visual Library

Brand visuals for Credit Counsel Elite: logos, colors, fonts, photos, videos, graphics, templates.
Source: creditcounselelite.com + team uploads · Last updated: 2026-11-19

## Structure
```
visual/
├── brand-guide.md          ← colors, fonts, logo usage rules (fill in)
├── asset-sources.md        ← every asset URL found on the website (to download)
├── logos/
│   ├── primary/            ← main logo (SVG + PNG, light & dark)
│   ├── secondary/          ← wordmark, stacked, horizontal variants
│   ├── icon/               ← favicon / avatar / app icon
│   └── press-logos/        ← "As seen in" outlets (Forbes, Yahoo Finance, NBC…)
├── colors/                 ← palette swatches (.ase, .png) — hex codes in brand-guide.md
├── fonts/                  ← font files or links + licenses
├── photos/
│   ├── founders/           ← Brandon & Jennifer
│   ├── members/            ← member win photos (with consent)
│   └── lifestyle/          ← travel, real estate, San Diego projects
├── videos/
│   ├── testimonials/       ← member success stories
│   ├── ads/                ← finished ad creatives
│   ├── podcast/            ← Ready. Set. Go. REI clips
│   └── b-roll/             ← raw footage
├── graphics/
│   ├── social/             ← IG/FB posts, stories, thumbnails
│   ├── web/                ← site banners, section images
│   └── ads/                ← static ad creatives
├── templates/              ← Figma/Canva/PSD templates (or links)
└── references/
    └── moodboard/          ← inspiration, competitor examples
```

## File rules
- **Naming:** `cce_<type>_<description>_<variant>.<ext>`, e.g. `cce_logo_primary_dark.svg`, `cce_video_testimonial_moshe_9x16.mp4`
- **Logos:** keep SVG master + PNG exports (transparent background)
- **Size limit:** GitHub rejects files over **100 MB** and slows down with large binaries. Store long/heavy videos in Google Drive and put a `links.md` in the folder with the share URL, title, ratio and duration.
- **Consent:** only store member photos/videos you have permission to use.
